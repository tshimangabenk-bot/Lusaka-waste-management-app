🚨 COMMON ISSUES & QUICK FIXES
═════════════════════════════════════════════════════════════════════════════

  ❌ "Port 5000 already in use"
     ✓ Fix: Close the batch window and try again
     ✓ Or: taskkill /F /IM python.exe

  ❌ "Cannot connect to database"
     ✓ Fix: Start XAMPP MySQL
     ✓ Create database in phpMyAdmin: http://localhost/phpmyadmin

  ❌ "ModuleNotFoundError"
     ✓ Fix: cd backend && pip install -r requirements.txt

  ❌ "Frontend shows blank page"
     ✓ Fix: Try http://localhost:8000/ (with trailing slash)
     ✓ Clear browser cache: Ctrl+Shift+Delete

  ❌ "Page not found / 404"
     ✓ Check that services are running (3 windows open)
     ✓ Check correct URL: 8000 for user, 8001 for admin


💡 TIPS & TRICKS
═════════════════════════════════════════════════════════════════════════════

  1. Keep all 3 windows open - closing one stops that service
  2. Services start in minimized mode - open them to see logs
  3. First startup may take 10-15 seconds to initialize database
  4. You can access phpMyAdmin at: http://localhost/phpmyadmin
     (Username: root, Password: blank)
  5. Backend logs show in Flask window - helpful for debugging
  6. Frontend errors visible in browser F12 console
