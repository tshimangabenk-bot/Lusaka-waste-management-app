# Smart Waste Management System — Lusaka City Council

A full-stack web application for Lusaka City Council to monitor smart bins, manage waste collection routes, process citizen reports, and reward residents for environmental participation.

## Architecture

| Layer | Technology | Hosted on |
|-------|-----------|-----------|
| Backend API | Flask 3.1 + PostgreSQL | Render |
| Admin Dashboard | Vanilla JS + Leaflet + Chart.js | Firebase Hosting (`admin` target) |
| Resident Portal | Vanilla JS + Leaflet | Firebase Hosting (`user` target) |
| Auth / Storage / Push | Firebase Admin SDK + FCM | Firebase |

## Quick Start (Local Development)

### 1. Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env            # fill in your values

flask db upgrade                # create tables
python seed.py                  # seed sample data (zones, admin user, etc.)
python run.py                   # starts on http://localhost:5000
```

Default admin login after seeding:
- **Email:** `admin@lcc.zm`
- **Password:** `admin123`

### 2. Frontends

Open these directly in your browser (or use VS Code Live Server):
- Admin Dashboard: `admin-dashboard/index.html`
- Resident Portal: `user-dashboard/login.html`

Both automatically point to `http://localhost:5000/api` when running on localhost.

## Deployment

### Backend → Render

1. Push this repo to GitHub.
2. On [render.com](https://render.com): **New → Blueprint** → connect this repo.
3. Render reads `render.yaml` and auto-creates the web service + PostgreSQL database.
4. In the Render dashboard, go to your `smart-waste-api` service → **Environment** and add:
   - `FIREBASE_CREDENTIALS_JSON` — paste the full contents of your Firebase service account JSON (one line).
5. After first deploy, open the **Shell** tab and run:
   ```bash
   cd backend && python seed.py
   ```

### Frontends → Firebase Hosting

The `firebase.json` is configured with two hosting targets: `user` and `admin`.

```bash
npm install -g firebase-tools
firebase login
firebase use smart-waste-management-s-6225c

# Link the two targets to your Firebase Hosting sites
firebase target:apply hosting user  smart-waste-lusaka-user
firebase target:apply hosting admin smart-waste-lusaka-admin

# Deploy both
firebase deploy --only hosting
```

> After deploying, update the admin redirect URL in `user-dashboard/login.html` and `user-dashboard/process_login.html` to match your actual admin hosting URL.

## Firebase Setup

The project uses Firebase project `smart-waste-management-s-6225c`. To enable all features:

1. **Auth:** Enable Email/Password in Firebase Console → Authentication → Sign-in methods.
2. **Storage:** Create a default bucket and set rules to allow authenticated uploads.
3. **FCM:** Web Push certificates are already configured via VAPID key in `firebase-config.js`.
4. **Authorized Domains:** Add your Render URL and Firebase Hosting URLs in Firebase Console → Authentication → Settings → Authorized domains.
