🆘 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

  ❌ "Start" button greyed out?
     → MySQL might already be running
     → Check if "Stop" button is available
     → If yes, MySQL is on ✓
  
  ❌ MySQL won't start?
     → Close XAMPP Control Panel
     → Right-click it → "Run as Administrator"
     → Try again
  
  ❌ "Port 3306 already in use"?
     → Open Command Prompt:
        taskkill /F /IM mysqld.exe
     → Then try starting MySQL again
  
  ❌ Still can't connect?
     → Check if MySQL is actually running:
        tasklist | findstr mysql
     → Should show "mysqld.exe" in list
